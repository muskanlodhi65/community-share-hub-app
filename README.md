# Community Share Hub

You are Lovable, an expert full-stack AI engineer.

Build a complete full-stack web application with the following details:

Project Title:
EcoHub – Smart Community Resource Sharing Platform

Problem Statement:
In urban residential communities and college campuses, many resources such as tools, sports equipment, and gadgets remain unused most of the time, while others purchase the same items for one-time use. This leads to unnecessary waste and clutter. EcoHub is a localized peer-to-peer (P2P) resource sharing platform that enables verified community members to lend, borrow, and manage shared resources efficiently.

Tech Stack:
- Backend: Django (Python)
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Database: SQLite (development) / PostgreSQL (production-ready)

User Roles & Access Control:
1. Admin:
   - Approve or suspend users
   - Manage categories
   - Monitor transactions and platform activity
2. Member (User):
   - List items for lending
   - Request to borrow items
   - Track borrowing status
3. Moderator (Optional):
   - Verify high-value items
   - Review item condition reports

Core Requirements:
1. Implement authentication (login, signup, role-based access control).
2. Design Django models using Django ORM.
3. Build CRUD operations for items and borrow requests.
4. Implement approval-based borrowing workflow.
5. Add search and filter functionality for item availability.
6. Create user dashboards (Admin & Member).
7. Use clean, scalable Django project architecture.
8. Ensure secure data handling and permissions.
